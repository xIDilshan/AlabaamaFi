# AlabaamaFi

**One place. Every move.**

AlabaamaFi is a DeFi interface built for Arc Network, bringing essential onchain asset management features together in one place.

🌐 **Live Website:** https://app.alabaamafi.xyz

---

## ✨ Features

- **Send** — Transfer supported assets between wallets.
- **Swap** — Swap supported tokens on Arc Network.
- **Bridge** — Cross-network asset transfers (coming soon).
- **Activity** — Explore wallet activity.
- **Wallet Connectivity** — Connect compatible Web3 wallets.

## 🌐 Network Information

- **Network:** Arc Mainnet
- **Chain ID:** 5042
- **Gas Token:** USDC
- **Block Explorer:** https://explorer.arc.io
- **Network Website:** https://arc.network
