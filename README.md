AlabaamaFi

One place to move, manage, and explore assets on Arc Network.

AlabaamaFi is a simple DeFi interface built for Arc Network. It brings common onchain actions into one clean interface, making it easier to interact with assets and explore wallet activity on Arc.

Features

- Send USDC between wallets
- Swap supported tokens on Arc
- Bridge USDC across supported networks
- Explore wallet activity and token balances
- Connect with EVM-compatible wallets
- Access Arc Testnet faucet
- View supported Arc assets

Built on Arc

AlabaamaFi is built around the Arc Network ecosystem and currently runs on Arc Testnet.

Supported assets include:

- USDC
- EURC
- cirBTC

Tech Stack

- Next.js
- TypeScript
- React
- Tailwind CSS
- wagmi
- viem
- Circle developer tools
- Arc Network
